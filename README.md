# Data-Structures
Python Data Structures 🐍

Welcome to my Python Data Structures practice notebook!

This notebook contains hands-on examples for learning Python's built-in collection types and practicing how to access and manipulate their contents.

## 📚 Topics Covered

### Lists

- Creating empty and populated lists
- Storing values of different types
- Checking a list's type and length
- Accessing items with positive and negative indexes
- Slicing lists
- Adding items with `append()`, `extend()`, and `insert()`
- Removing items with `pop()`, `remove()`, and `clear()`
- Sorting and reversing lists
- Creating nested lists and accessing their elements

### Tuples

- Creating tuples
- Accessing tuple elements with indexes
- Checking tuple length
- Exploring tuple operations and their limitations

### Sets

- Creating sets and storing unique values
- Adding and removing items
- Clearing a set
- Comparing sets with `intersection()`, `union()`, and `difference()`

### Dictionaries

- Creating dictionaries as key-value collections
- Exploring dictionary keys and values with `keys()`, `values()`, and `items()`
